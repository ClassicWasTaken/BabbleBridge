Babble Bridge original artwork and third-party typography

ORIGINAL BABBLE BRIDGE ARTWORK (2026)
bridge-logo.svg is the original generic VR headset mark. bridge-logo.png and
../Bridge.ico are raster/icon renderings of that mark; BridgeMarks.xaml provides
its white WPF vector form. Rebuild the generated assets with:
  python installer/assets/generate-art.py
The same script renders installer/assets/wizard-panel.png from the original
headset mark, original layout, spline-flow particle artwork and licensed fonts.
The mark uses a rounded visor, nose bridge, side temples and a short top strap;
it does not trace a specific commercial headset or use Valve, Steam, or Project
Babble logos. No official logo, banner, icon geometry or website animation is included.
The bridge-logo filenames and BridgeLogoWhite resource key are retained for app
compatibility; the current artwork depicts a headset rather than an architectural bridge.

ParticleField.cs independently implements a changing closed Catmull-Rom loop,
per-particle speeds and a damped cursor force. Its control points and parameters
are original to Babble Bridge. Spline interpolation is standard mathematics.
The installer uses the project's own spline motif, not a website-derived pattern.
These original code/art assets follow the Babble Bridge project license.
