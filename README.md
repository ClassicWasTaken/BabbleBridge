A Windows app built for **Babble Frame Runtime on Steam Frame**. It sends your headset’s eye and face tracking to VRChat through compatible **VRCFaceTracking SDK** modules. Supports traditional VRCFT avatars and VRChat’s native face-tracking SDK beta.

![Steam Frame Babble Bridge running on Windows](docs/images/app-running.jpg)

## Get started

1. Install the app and import your **Baballonia module ZIP**. The module is not included.
2. Start **Babble Frame Runtime** on your Steam Frame, on the same network as your PC.
3. Enable **OSC** in VRChat and select a face-tracking avatar.

For desktop Baballonia, select **Connection → Baballonia desktop → Save connection** and enable its VRCFaceTracking output to `127.0.0.1:8888`. Jerry’s templates are supported.
